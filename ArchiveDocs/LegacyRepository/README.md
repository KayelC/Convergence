# Retired Repository Entry Point

This directory preserves the files that occupied the Git repository root before
the clean Convergence product was promoted there.

The contents are historical evidence only:

- `JRPG.sln` is the retired solution and references projects that are no longer
  active.
- `README-retired.md` describes the retired prototype rather than the generic
  Convergence Framework.
- `Documentation/` is the former root documentation tree.
- `OldFilesArchive/` contains older prototype source, datasets, reports, and
  experiments.

None of these files are referenced by `Convergence.sln`, copied by an active
project, or authoritative for current behavior. Start from the repository-root
`README.md`, `Convergence.sln`, and `docs/` directory instead.
